# 🏫 IoT-Based Smart Classroom Management System

An intelligent classroom management system using **Arduino, IoT, and a Web Dashboard** to monitor classroom conditions and automate electrical devices.

## 📌 About the Project

The IoT-Based Smart Classroom Management System aims to make classrooms smarter, more efficient, and energy-friendly.

The system uses sensors connected to an Arduino to monitor classroom conditions and detect student presence. A web-based dashboard provides a user-friendly interface to monitor classroom information and manage connected devices.

## 🎯 Objectives

- Monitor classroom temperature.
- Detect student presence using an IR sensor.
- Automate LED lighting based on student detection.
- Control electrical devices using a relay module.
- Display classroom information on an LCD.
- Provide a web dashboard for classroom monitoring and management.

## 🛠️ Hardware Components

- Arduino Uno
- IR Sensor
- LM35 Temperature Sensor
- 16×2 I2C LCD Display
- LED
- Relay Module
- Connecting Wires
- Breadboard

## 💻 Software & Technologies

- Arduino IDE
- HTML
- CSS
- JavaScript
- Web Serial API
- Chart.js

## ⚙️ Working Principle

1. The IR sensor detects the presence of a person.
2. The Arduino processes sensor readings.
3. The LM35 measures classroom temperature.
4. The LED can be controlled automatically based on the detected presence.
5. The relay module provides switching control for connected devices.
6. The LCD displays relevant information.
7. The web dashboard displays the data received from Arduino through serial communication.
